一句话：这是你自己运行的聊天工具。
聊天记录、记忆库、分支存档都存在你运行服务的机器或你的浏览器里，我们不做账号体系，也不收集统计。 唯一的对外通信，是你（或管理员）配置的模型厂商 API。

一、谁在处理你的数据

E-dreikanterbot 是自托管软件：源码在你手里，服务跑在哪台机器由你决定。

  • 自己部署自己用：数据只在你自己的电脑/服务器上，开发者接触不到。
  • 使用他人搭建的实例：那台实例的运营者能看到你的请求内容，请以该实例运营方公布的政策为准。

二、会产生哪些数据，存在哪里

数据存在哪里是否离开你的控制
对话内容、分支、标题你的浏览器存储（localStorage / IndexedDB）否
长期记忆条目你的浏览器存储否
界面设置（模型、温度、主题等）你的浏览器存储否
服务端配置的 API Key服务器的环境变量 / .env 文件否（只用于向模型厂商发起请求）
模型回复实时返回给浏览器，不落服务端数据库否

三、数据流：消息去了哪里

  1. 你在网页里输入内容 → 发到你自己的服务端（/api/chat 之类的本地接口）；
  2. 服务端用**你自己配置的 API Key**，把这段对话转发给你选择的模型厂商（当前支持 DeepSeek、Kimi/Moonshot）；
  3. 厂商返回结果 → 服务端流式回传给你 → 浏览器显示并存入本地。

除上述厂商外，本软件不向任何第三方发送数据：没有统计 SDK、没有广告、没有崩溃上报、没有远程配置。

⚠️ 请知悉：调用云端模型时，对话内容会按该厂商的隐私政策处理（例如 DeepSeek、Moonshot 的开放平台条款）。若你处理敏感信息，请自行评估或改用本地模型。

四、API Key 怎么存

  • Key 只写在服务端的 .env 或环境变量（DEEPSEEK_API_KEY / KIMI_API_KEY），不会下发到浏览器；
  • 接口只返回「是否已配置」（keyConfigured: true/false），不返回 Key 明文；
  • 请勿把 .env 提交进 Git；仓库已用 .gitignore 排除。

五、我们收集什么

不收集：个人身份信息、设备标识符、位置、通讯录、相册、应用使用埋点。

服务端默认只写本地日志（请求时间、状态码、错误信息），用于排查问题；日志留在你自己的机器上，不含 API Key 明文。

六、如何删除数据

  • 浏览器内：会话列表逐条删除，或清除站点数据（设置 → 网站数据 → 删除）；
  • 服务端：删除部署目录即可（本软件不使用外部数据库）；
  • 记忆库：在「记忆」面板里逐条删除或整体清空。

七、儿童与敏感信息

本工具面向具备基本判断力的使用者，不面向 14 周岁以下儿童单独设计。请勿在其中输入身份证号、银行卡、医疗记录等高度敏感信息。

八、政策变更

如未来版本新增账号体系、云端同步等功能，会先更新本政策并在界面提示；自托管部署时请以你拉取的那一版代码所附政策为准。

English Summary

E-dreikanterbot is a self-hosted chat client. Conversations, memories and settings live in your own browser storage; the server only holds the API key you configured and forwards requests to the model provider you chose (DeepSeek / Moonshot). No analytics, no ads, no tracking, no third-party SDKs. If you use someone else's deployment, that operator's policy applies.
