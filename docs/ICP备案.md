# ICP 备案说明（Dreikanter photo）

> 一句话：**代码这边已经把「备案号展示位」做好了；但备案本身必须由你（网站主办者）
> 去工信部系统申请，需要域名、境内服务器和实名材料，任何人代不了。**

---

## 1. 什么情况下需要备案

| 场景 | 是否需要 ICP 备案 |
|---|---|
| 纯本地使用（双击 `index.html`，`file://`） | 不需要 |
| 只在内网/局域网访问 | 一般不需要 |
| 部署到**中国大陆境内**服务器，用域名对外提供访问 | **必须备案**（未备案会被接入商拦截、域名被拉黑） |
| 部署到境外/香港服务器 | 不需要 ICP，但速度与合规另说 |
| 有付费/交易功能 | 需要备案 **+** 经营性 ICP 许可证（EDI/ICP 证） |

本项目是纯静态前端（无后端、无数据库），备案时通常按「**非经营性网站**」申报。

## 2. 备案要准备什么

1. **域名**：已完成实名认证的域名（`.com/.cn` 等），注册人与主体一致。
2. **境内服务器**：阿里云 / 腾讯云 / 华为云等，且已购买 3 个月以上（多数接入商要求）。
3. **主体材料**：
   - 个人：身份证正反面、本人手机号、邮箱、手持身份证照（部分省份）；
   - 企业：营业执照、法人身份证、网站负责人身份证、授权书。
4. **网站信息**：网站名称（个人站不能含「公司/商城/新闻」等敏感词）、服务内容、首页地址。
5. **幕布拍照**（部分省份/接入商要求）：接入商寄幕布，站在幕布前拍照上传。

## 3. 流程

1. 在**接入商**（如阿里云「ICP 代备案系统」）提交初审 → 接入商 1–2 个工作日审核；
2. 接入商提交**省通信管理局** → 官方审核约 **7–20 个工作日**；
3. 通过后下发备案号，形如 `京ICP备2026000000号-1`；
4. 拿到号后，**必须**在网站首页底部展示备案号，并链接到 `https://beian.miit.gov.cn`；
5. 若涉及论坛/评论等交互，还需做**公安联网备案**（30 日内），拿到 `京公网安备 …号`。

## 4. 本项目怎么填备案号

备案号有两条路，任选其一：

**A. 改代码（推荐，进版本库）**

编辑 [`js/site.js`](../js/site.js)：

```js
const SITE = {
  icp: '京ICP备2026000000号-1',      // ← 填这里
  police: '京公网安备 11010802000000号', // 有公安备案再填
  ...
};
```

**B. 不改代码（运维热填）**

在浏览器控制台执行一次，之后每次打开都会读到（存在 localStorage）：

```js
localStorage.setItem('siteLegal', JSON.stringify({
  icp: '京ICP备2026000000号-1',
  police: '京公网安备 11010802000000号'
}));
```

填好后，备案行会自动出现在：

- **起始页底部**（`#welLegal`，带 © 版权）
- **帮助 → 关于 Dreikanter photo** 对话框底部

未填写时显示「ICP 备案：待填写」——**上线前必须填**，否则不合规。

备案号渲染由 `Site.legalNode()` 统一负责，链接带 `target="_blank" rel="noopener noreferrer nofollow"`。

## 5. 自检怎么验

`node tests/run.js` 里有 4 项相关自检：

- `ICP 备案 · 未配置时给出待填写提示`
- `ICP 备案 · 配置后渲染可点击备案号`（校验 href / rel / target）
- `起始页 · 备案行挂进 DOM`
- `起始页 · 新版布局与操作入口`（含版本号同步）

## 6. 常见坑

- **备案号必须和域名一一对应**，换域名要变更备案；
- 备案期间域名**不能**解析到境内服务器对外开放，否则会被拦截；
- 个人备案的网站**不能**有经营性内容（广告位、付费下载、电商）；
- 备案号展示**不能**做成图片或隐藏，必须可点击、可读文本；
- 部分接入商要求首页底部同时放「© 版权」与「备案号」，本项目已内置。
