# App 备案（移动互联网应用程序备案）办事指南

> 针对本项目：Dreikanter photo 的 **HarmonyOS HAP** 与 **Android APK**。
> 本文只讲「要不要办、怎么办、材料怎么准备」，具体以省通信管理局与接入商要求为准。

---

## 0. 先把两个"备案"分清

| | 网站 ICP 备案 | **App 备案**（本文） |
|---|---|---|
| 管什么 | 网站/域名 | 移动应用程序（App/HAP/APK/小程序） |
| 依据 | 《互联网信息服务管理办法》 | 工信部 2023 年 8 月《关于开展移动互联网应用程序备案工作的通知》 |
| 触发条件 | 自己的域名 + 境内服务器 | 在境内**从事互联网信息服务**的 App（含上架、公开分发） |
| 自己侧载自己用 | 不需要 | **不需要** |
| 上架应用市场 / 公开下载 | 不需要（App 不涉及域名） | **需要** |

**关键结论**：你现在只是想在自己那台 NEXT 设备上用 → 用调试签名 + `hdc install` 装 HAP，
**不用备案**。等你打算给一群人用、或者上架华为应用市场，才走本文流程。

## 1. 什么时候必须办

- 上架**华为应用市场**（AppGallery）——商店审核会查备案号，没有直接驳回；
- 在自己的官网/公众号/网盘**公开提供下载**；
- 通过任何渠道向**不特定公众**提供（哪怕不上架）。

不需要的情形：

- 只装自己/家人/同事的设备（调试签名、内测分发）；
- 纯离线工具、不提供任何网络服务？（仍建议办，判罚看"是否提供服务"，不看是否联网）；
- 只做浏览器网页（那是网站备案，不是 App 备案）。

## 2. 办之前要准备什么

### 主体材料
- 个人：身份证正反面、手持身份证照（部分省）、本人手机号、邮箱；
- 企业：营业执照、法人身份证、App 负责人身份证、授权书。

### App 材料
- **App 名称**：与安装后桌面显示一致（本项目为 `Dreikanter photo`）；
- **包名 / BundleName**：
  - HarmonyOS：`design.ansel.dreikanter`
  - Android：`design.ansel.dreikanter`
- **版本号**：`18.2.0`（与 `AppScope/app.json5`、`package.json` 一致）；
- **功能简介**：一句话 + 100 字内描述（见 §4 模板）；
- **服务内容分类**：选「**工具类 / 图像处理**」；不要选「新闻」「出版」「社交」「直播」等需要前置审批的类别；
- **签名证书指纹**（SHA-256）：备案表单会要，DevEco 生成调试证书后可在
  `Project Structure → Signing Configs` 里复制，或对 HAP 执行
  `hdc shell bm dump -n design.ansel.dreikanter` 查看；
- **图标**：512×512 PNG（仓库 `icons/icon-512.png` 可直接用）。

### 接入商（必填项）
App 备案必须通过**网络接入服务提供者**提交，两种都可以：

1. **云服务商**：华为云 / 阿里云 / 腾讯云（有"App 备案"入口，和网站备案同一套系统）；
2. **应用分发平台**：华为应用市场提供代备案通道（上架时一并提交）。

> 本项目是纯前端、无后端。备案时"服务器"一栏填你实际用的云资源即可；
> 如果完全不用云，只上架应用市场，就走**应用市场代备案**这条路。

## 3. 流程（以华为云为例）

1. 注册华为云 → 完成**实名认证**（个人/企业）；
2. 进入「备案 → App 备案」，选择主体 → 新增 App；
3. 填 §2 的信息，上传材料；
4. 华为云初审（1–2 个工作日，会电话核验）；
5. 提交**省通信管理局** → 审核 **7–20 个工作日**；
6. 通过后下发**备案号**（形如 `京ICP备2026000000号-12A`，App 备案号带 `A` 后缀）；
7. 把备案号填进应用市场后台（华为要求上架时填）。

## 4. 直接能抄的填写模板

**App 名称**：Dreikanter photo

**功能简介（100 字内）**：

> 一款本地运行的图像编辑工具，支持图层、选区、曲线、滤镜、批量导出等 Photoshop 式操作，
> 另提供面向移动端的简化编辑模式。全部处理在设备本地完成，不上传用户照片，不含社交与内容分发功能。

**服务内容**：工具类 — 图像处理

**是否涉及用户生成内容（UGC）**：否
**是否涉及新闻/出版/社交/直播**：否
**是否收集个人信息**：否（仅本地存储，不上传）
**是否有付费**：否

> 这几项答"否"能显著减少审核问询；如果以后加了云同步/账号体系，要回来变更。

## 5. 上架华为应用市场的额外要求

| 项目 | 要求 |
|---|---|
| 开发者账号 | 华为开发者联盟实名（个人可，需身份证 + 人脸） |
| 软件著作权 | 工具类一般**不强制**，但被要求时需提供（可自行申请，约 30 个工作日） |
| 隐私政策 | 必须提供 URL（可用 GitHub Pages 免费托管一份） |
| App 备案号 | **必须** |
| 内容合规 | 不得含未备案的第三方 SDK、不得引导下载站外包 |

## 6. 常见坑

- **备案主体 = 开发者账号主体**，不一致会被驳回；
- **App 名称必须与桌面图标显示名一致**，改名前先想好（改名要变更备案）；
- **包名不能改**，改了等于新 App，要重新备案；
- 备案通过后 **30 日内**做**公安联网备案**（部分省份要求）；
- 每年要**年报**，忘年会注销；
- 只做内测（TestFlight 式）也别公开下载链接，公开即视为分发。
